# Plan 5 — Rute `/lab` dan blok Lab di homepage

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menambahkan rute `/lab` yang menampilkan mini project milik Sutan, plus blok "Mini Project" di homepage — **hanya** kalau isinya sudah nyata.

**Architecture:** Data mini project tinggal di `src/data/portfolio.ts` (array `lab`). Kartu lab punya bentuk sendiri (lebih ringan dari kartu proyek utama: tidak ada deskripsi panjang, tidak ada modal detail, yang penting tautan demo + sumber + satu kalimat keputusan teknis).

**Tech Stack:** Next.js 16 · React 19 · TypeScript · Tailwind CSS v3 · next-intl · Vitest

**Spec:** `docs/superpowers/specs/2026-10-21-portfolio-v3-design.md` §10 dan §5.1 (repo `sutannn7/sutan-akbar-portfolio`)

**Prasyarat (WAJIB):** Plan 2, 3, 4 selesai **dan** ketiga mini project sudah live di Vercel. Kalau salah satu belum live, **jangan** kerjakan plan ini — kirim `/lab` kosong adalah persis anti-goal "halaman kosong" di spec §2.

## Global Constraints

- Repo: `C:\Users\lenovo\portofolio-v3`, branch `feature/v3-reskin` (atau branch lanjutan dari Plan 1).
- Selalu `npm.cmd`, bukan `npm`.
- `lab` adalah array di `src/data/portfolio.ts` — field: `slug, title: Localised, tagline: Localised, problem: Localised, decision: Localised, techStack: string[], repoUrl: string, demoUrl: string, year: string, image: string`.
- `demoUrl` dan `repoUrl` **wajib** ada dan harus `https://` — tidak boleh kosong, tidak boleh `#`.
- Tidak boleh ada halaman kosong: kalau `lab` kosong, rute `/lab` **tidak dibuat** dan blok homepage **tidak** dirender.
- Tidak boleh ada teks Indonesia yang dikunci di komponen.
- Warna: aksen lime `#C8F246`; di light mode lime hanya boleh jadi fill, bukan warna teks.

## Review Focus

1. **Rute `/lab` hanya ada kalau isinya ada** — kalau `lab.length === 0`, `src/app/lab/page.tsx` tidak boleh ada dan link nav `/lab` tidak boleh dirender. Test: file rute tidak ada, dan komponen mengembalikan `null`.
2. **Semua link lab hidup** — setiap `demoUrl` dan `repoUrl` harus `https://` dan dit Endowment test yang sama seperti validasi proyek utama.
3. **Konsistensi visual** — kartu lab harus memakai token yang sama dengan situs utama (bg-surface, border-border, text-foreground). Reviewer harus bisa membandingkan kartu lab dan kartu proyek.
4. **Badge level tidak boleh pakai angka** — kalau kartu lab menampilkan tingkat Difficult, itu harus badge teks, bukan persentase.
5. **Homepage block lab tidak boleh menduplikasi `/projects`** — isi homepage hanya 3 lab terbaru dengan link "Lihat semua".

```tsx
import { describe, it, expect } from 'vitest';
import { render, screen } from '@testing-library/react';
import { LabCard } from '@/components/lab/LabCard';

const item = {
  slug: 'command-palette',
  title: { id: 'Command Palette', en: 'Command Palette' },
  tagline: { id: 'Mencari aksi tanpa menyentuh mouse', en: 'Find actions without touching the mouse' },
  problem: { id: 'Mencari aksi lambat', en: 'Slow to find actions' },
  decision: { id: 'Subsequence fuzzy match', en: 'Subsequence fuzzy match' },
  techStack: ['Next.js', 'TypeScript'],
  repoUrl: 'https://github.com/sutannn7/sutan-command-palette',
  demoUrl: 'https://sutan-command-palette.vercel.app',
  year: '2026',
  image: '/projects/command-palette.png',
};

describe('LabCard', () => {
  it('menampilkan tautan demo dan source yang absolut', () => {
    render(<LabCard item={item} locale="id" />);
    expect(screen.getByRole('link', { name: /demo/i })).toHaveAttribute('href', item.demoUrl);
    expect(screen.getByRole('link', { name: /source/i })).toHaveAttribute('href', item.repoUrl);
  });
  it('menampilkan tech stack', () => {
    render(<LabCard item={item} locale="id" />);
    expect(screen.getByText('Next.js')).toBeInTheDocument();
  });
  it('tidak pernah merender tautan kosong', () => {
    render(<LabCard item={{ ...item, demoUrl: '' }} locale="id" />);
    expect(screen.queryByRole('link', { name: /demo/i })).not.toBeInTheDocument();
  });
});
```
